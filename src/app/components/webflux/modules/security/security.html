SecurityWebFilterChain

Configuración de seguridad reactiva con Spring Security WebFlux.

@EnableWebFluxSecurity
Habilita la seguridad WebFlux. No hay WebSecurityConfigurerAdapter — se define un @Bean de SecurityWebFilterChain directamente.
SecurityWebFilterChain
La cadena de filtros de seguridad reactiva. Se crea con HttpSecurity.build() (en Spring MVC) → ahora ServerHttpSecurity.build() reactivo.
ServerHttpSecurity
Equivalente reactivo de HttpSecurity. Configura: .csrf(), .authorizeExchange(), .httpBasic(), .formLogin(), .oauth2ResourceServer().
PathMatcher reactivo
authorizeExchange en lugar de authorizeRequests. Patterns Ant: .pathMatchers("/api/**").authenticated(). Método: .pathMatchers(HttpMethod.POST, ...).
@Configuration
@EnableWebFluxSecurity
public class SecurityConfig {{ '{' }}
  @Bean
  public SecurityWebFilterChain securityChain(ServerHttpSecurity http) {{ '{' }}
    return http
      .csrf(ServerHttpSecurity.CsrfSpec::disable)
      .authorizeExchange(ex -> ex
        .pathMatchers("/public/**").permitAll()
        .anyExchange().authenticated())
      .oauth2ResourceServer(oauth2 -> oauth2.jwt(Customizer.withDefaults()))
      .build();
  {{ '}' }}

ReactiveAuthenticationManager

Autenticación reactiva con usuario/contraseña y carga de usuarios desde base de datos.

ReactiveAuthenticationManager
Interfaz: authenticate(Authentication) → Mono<Authentication>. Reemplaza a AuthenticationManager bloqueante. Se registra como @Bean.
ReactiveUserDetailsService
loadUserByUsername(String) → Mono<UserDetails>. Implementa para cargar usuarios desde R2DBC o cualquier fuente reactiva. Spring auto-configura el AuthenticationManager.
PasswordEncoder
BCryptPasswordEncoder — mismo que Spring MVC. Para comparación reactiva: passwordEncoder.matches(raw, encoded). No hay versión reactiva, es CPU-bound.
MapReactiveUserDetailsService
Implementación en memoria de ReactiveUserDetailsService. Útil para tests y desarrollo. new MapReactiveUserDetailsService(user1, user2).
@Service
public class UserDetailsServiceImpl implements ReactiveUserDetailsService {{ '{' }}
  public Mono<UserDetails> loadUserByUsername(String username) {{ '{' }}
    return userRepo.findByUsername(username)
      .map(u -> User.withUsername(u.getUsername())
        .password(u.getPassword())
        .roles(u.getRole())
        .build());

JWT en WebFlux

Autenticación stateless con tokens JWT usando AuthenticationWebFilter.

AuthenticationWebFilter
Filtro que extrae y valida credenciales. Para JWT: extrae el token del header Authorization, valida la firma y crea la Authentication. Se añade a ServerHttpSecurity.
ServerHttpRequest extracción
exchange.getRequest().getHeaders().getFirst("Authorization"). Luego extraer Bearer token y validar con la biblioteca JWT (jjwt, nimbus-jose).
OAuth2 Resource Server
Spring Security built-in: .oauth2ResourceServer(o -> o.jwt(Customizer.withDefaults())). Configura automáticamente el validador JWT con JWKS endpoint o clave pública.
ReactiveSecurityContextHolder
Para obtener el usuario autenticado: ReactiveSecurityContextHolder.getContext().map(SecurityContext::getAuthentication). Propagado vía Reactor Context.
# Spring OAuth2 Resource Server con JWT
spring.security.oauth2.resourceserver.jwt.issuer-uri=https://auth.example.com
// Acceder al usuario actual desde el endpoint
@GetMapping("/me")
public Mono<String> me(@AuthenticationPrincipal Jwt jwt) {{ '{' }}
  return Mono.just(jwt.getSubject());

@PreAuthorize Reactivo y CORS

Control de acceso a nivel de método y configuración CORS en WebFlux.

@PreAuthorize reactivo
Requiere @EnableReactiveMethodSecurity. Las expresiones SpEL funcionan igual: @PreAuthorize("hasRole('ADMIN')"), @PreAuthorize("hasAuthority('WRITE')").
@PostAuthorize
Se evalúa DESPUÉS de ejecutar el método. Puede acceder al resultado con returnObject. En contexto reactivo, se evalúa cuando el Mono/Flux emite.
CORS WebFlux
Configurar CORS en WebFluxConfigurer: addCorsMappings(registry). O por endpoint: @CrossOrigin. O en SecurityWebFilterChain con .cors().
CorsConfigurationSource
@Bean de CorsConfigurationSource con UrlBasedCorsConfigurationSource. Define origins, methods, headers permitidos. Referenciado desde SecurityWebFilterChain.
@Configuration
@EnableReactiveMethodSecurity
public class MethodSecurityConfig {{ '{' }} {{ '}' }}

  return repo.deleteById(id);
