33Módulo 6 · WebClient

WebClient Setup

El cliente HTTP reactivo de Spring — reemplaza a RestTemplate en aplicaciones WebFlux.

??
WebClient.Builder
Configura baseUrl, headers por defecto, codecs, filtros. Cada instancia es inmutable y thread-safe. Reutiliza la instancia — no crees una por petición.
??
Connection Pool
WebClient usa Reactor Netty internamente con connection pool. Configurable via HttpClient.create() + ConnectionProvider. Comparte conexiones entre peticiones.
??
Headers por defecto
.defaultHeader("Accept", "application/json"), .defaultHeaders(h -> h.setBearerAuth(token)). Se aplican a todas las peticiones del cliente.
??
@Bean WebClient
Declara WebClient como @Bean con baseUrl configurada. Inyecta en servicios. Usa WebClient.Builder (auto-configurado por Spring Boot) para personalizar.
@Bean
public WebClient webClient(WebClient.Builder builder) {{ '{' }}
  return builder
    .baseUrl("https://api.example.com")
    .defaultHeader(HttpHeaders.CONTENT_TYPE, "application/json")
    .defaultHeader(HttpHeaders.ACCEPT, "application/json")
    .build();
{{ '}' }}

GET y POST Reactivos

Peticiones HTTP reactivas: retrieve, bodyToMono, bodyToFlux, bodyValue.

// GET ? Mono
Mono<Product> getProduct(Long id) {{ '{' }}
  return webClient.get()
    .uri("/products/{{ '{' }}id{{ '}' }}", id)
    .retrieve()
    .bodyToMono(Product.class);
{{ '}' }}
// GET ? Flux (colección)
Flux<Product> getAll() {{ '{' }}
  return webClient.get()
    .uri("/products")
    .retrieve()
    .bodyToFlux(Product.class);
{{ '}' }}
// POST con body
Mono<Product> create(ProductDTO dto) {{ '{' }}
  return webClient.post()
    .uri("/products")
    .bodyValue(dto)  // serializa a JSON
    .retrieve()
    .bodyToMono(Product.class);
{{ '}' }}
retrieve() es el método simplificado. exchangeToMono() da acceso completo al ClientResponse (status code, headers, body).
35Módulo 6 · WebClient

Manejo de Errores HTTP

Gestionar respuestas 4xx y 5xx reactivamente con onStatus y excepciones personalizadas.

??
Comportamiento por defecto
retrieve() lanza WebClientResponseException para 4xx y 5xx. Las subclases incluyen: WebClientResponseException.NotFound, .BadRequest, etc.
??
onStatus()
Personaliza el manejo por status code: .onStatus(HttpStatus::is4xxClientError, response -> ...). El callback retorna Mono<Throwable> para propagar la excepción.
??
exchangeToMono
Acceso completo al ClientResponse: .exchangeToMono(resp -> resp.statusCode().is2xxSuccessful() ? resp.bodyToMono(T.class) : resp.createException().flatMap(Mono::error)).
??
ParameterizedTypeReference
Para tipos genéricos: bodyToMono(new ParameterizedTypeReference<List<Product>>(){{ '{' }}{{ '}' }}). Mantiene la información de tipo en tiempo de ejecución.
webClient.get().uri("/products/{{ '{' }}id{{ '}' }}", id)
  .retrieve()
  .onStatus(HttpStatus::is4xxClientError, resp ->
    resp.bodyToMono(ErrorDTO.class)
      .map(err -> new ProductNotFoundException(err.message())))
  .onStatus(HttpStatus::is5xxServerError, resp ->
    Mono.error(new ServiceUnavailableException()))
  .bodyToMono(Product.class);
36Módulo 6 · WebClient

Timeouts, Retry y ExchangeFilterFunction

Resiliencia en llamadas externas: timeouts, reintentos con backoff y filtros transversales.

??
timeout()
.bodyToMono(T.class).timeout(Duration.ofSeconds(5)). Emite TimeoutException si no hay respuesta en el tiempo dado. Combina con onErrorResume para fallback.
??
retryWhen
.retryWhen(Retry.backoff(3, Duration.ofMillis(500)).filter(t -> t instanceof ServiceUnavailableException)). Solo reintenta errores de servidor, no de cliente (4xx).
??
ExchangeFilterFunction
Middleware para WebClient: intercepta cada petición/respuesta. útil para logging, autenticación automática (agregar token), métricas, tracing. Se añade con .filter().
??
Logging filter
ExchangeFilterFunction.ofRequestProcessor(req -> {{ '{' }} log(req); return Mono.just(req); {{ '}' }}). Para respuestas: ofResponseProcessor(). No bloquea el pipeline.
// ExchangeFilterFunction para añadir Bearer token
ExchangeFilterFunction authFilter =
  ExchangeFilterFunction.ofRequestProcessor(req ->
    Mono.just(ClientRequest.from(req)
      .header("Authorization", "Bearer " + getToken())
      .build()));
// Aplicar filter al builder
WebClient client = WebClient.builder()
  .filter(authFilter)
  .build();
