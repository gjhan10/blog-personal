Records (Java 16 — JEP 395)

Un record es una clase inmutable compacta. El compilador genera automáticamente constructor canónico, getters, equals(), hashCode() y toString().

  // equals, hashCode, toString...
{{ '}' }}

46Java 17

Sealed Classes (Java 17 — JEP 409)

Una clase o interfaz sealed controla qué clases pueden extenderla con la cláusula permits. Combinadas con switch de patrón garantizan exhaustividad.

Las subclases permitidas deben ser: final (no más subclases), sealed (continúa la jerarquía) o non-sealed (abre la jerarquía).
47Java 21

Pattern Matching en switch (Java 21 — JEP 441)

Java 21 estabilizó el pattern matching en switch. Combina type test con extracción de variable en un solo case. Las when guards permiten condiciones adicionales.

switch (obj) {{ '{' }}
case Integer i when i > 0 -> ...
case String s -> ...
case null -> ...
default -> ...
{{ '}' }}
48Java 21

Virtual Threads — Project Loom (Java 21 — JEP 444)

Los Virtual Threads son hilos ultraligeros gestionados por la JVM, no por el OS. Permiten millones de hilos concurrentes sin cambiar el modelo de programación.

Hilo de plataforma
~1 MB de stack por hilo
Límite: ~thousands
Gestionado por el OS
Virtual Thread
~Kilobytes de stack
Límite: millones
Gestionado por la JVM
49Java 21

Text Blocks & String Templates

Los Text Blocks (Java 15+) permiten strings multilínea con sangría automática usando """ ... """. .formatted() es el mecanismo de interpolación moderno.

Java 21 introduce los String Templates (JEP 430 preview). La sintaxis definitiva (STR."\{{ '{' }}expr{{ '}' }}") se revisa en Java 22–24 para mayor seguridad.
