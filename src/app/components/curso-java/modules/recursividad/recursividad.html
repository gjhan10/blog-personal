Recursividad en Java

Un método es recursivo cuando se llama a sí mismo para resolver un problema reduciéndolo a subproblemas más pequeños del mismo tipo. Toda función recursiva correcta necesita dos componentes:

  • Caso base — condición que devuelve un resultado directo sin más llamadas recursivas.
  • Caso recursivo — reduce el problema y delega en una llamada más pequeña.
  • Cada llamada ocupa un frame en la call stack. Sin caso base → StackOverflowError.
  • La recursión es elegante para problemas de naturaleza recursiva: árboles, grafos, divide y vencerás.
  • Java NO aplica Tail Call Optimization (TCO) — para entradas grandes usa iteración o memoización.

Anatomía de una función recursiva

Factorial — la función clásica
static long factorial(int n) {{ '{' }}
  if (n <= 1) return 1;          // ← caso base
  return n * factorial(n - 1);  // ← caso recursivo
{{ '}' }}
// factorial(5) → 5*4*3*2*1 = 120
Traza de factorial(4): 4 × factorial(3) → 4 × 3 × factorial(2) → 4 × 3 × 2 × factorial(1) → 4 × 3 × 2 × 1 = 24. La pila se desenrolla de abajo hacia arriba.

Recursión directa vs indirecta

Directa — se llama a sí mismo
static int suma(int n) {{ '{' }}
  if (n == 0) return 0;
  return n + suma(n - 1);
{{ '}' }}
Indirecta — A llama a B, B llama a A
static boolean esPar(int n) {{ '{' }}
  return n == 0 || esImpar(n - 1);
{{ '}' }}
static boolean esImpar(int n) {{ '{' }}
  return n != 0 && esPar(n - 1);
{{ '}' }}

Recursión vs Iteración — comparativa

Recursivo — riesgo StackOverflow con n grande
static long fibRec(int n) {{ '{' }}
  if (n <= 1) return n;
  return fibRec(n-1) + fibRec(n-2);
{{ '}' }}
// O(2ⁿ) — exponencial
Iterativo — O(n) tiempo, O(1) espacio
static long fibIter(int n) {{ '{' }}
  if (n <= 1) return n;
  long a = 0, b = 1;
  for (int i = 2; i <= n; i++) {{ '{' }}
    long t = a + b; a = b; b = t;
  {{ '}' }}
  return b;
{{ '}' }}

Memoización — el mejor de los dos mundos

Fibonacci con memoización — O(n) tiempo y espacio
static Map<Integer, Long> memo = new HashMap<>();

static long fib(int n) {{ '{' }}
  if (n <= 1) return n;
  if (memo.containsKey(n)) return memo.get(n);
  long r = fib(n-1) + fib(n-2);
  memo.put(n, r);
  return r;
{{ '}' }}

Problemas clásicos

Potencia eficiente — O(log n)
static long potencia(long base, int exp) {{ '{' }}
  if (exp == 0) return 1;
  if (exp % 2 == 0) {{ '{' }}
    long half = potencia(base, exp/2);
    return half * half;
  {{ '}' }}
  return base * potencia(base, exp-1);
{{ '}' }}
Torres de Hanói — O(2ⁿ)
static void hanoi(int n, String desde,
                  String hasta, String aux) {{ '{' }}
  if (n == 1) {{ '{' }}
    System.out.println(desde + " → " + hasta);
    return;
  {{ '}' }}
  hanoi(n-1, desde, aux, hasta);
  System.out.println(desde + " → " + hasta);
  hanoi(n-1, aux, hasta, desde);
{{ '}' }}
Búsqueda binaria recursiva — O(log n)
static int bSearch(int[] arr, int key,
                  int lo, int hi) {{ '{' }}
  if (lo > hi) return -1;
  int mid = (lo + hi) / 2;
  if (arr[mid] == key) return mid;
  if (arr[mid] < key) return bSearch(arr, key, mid+1, hi);
  return bSearch(arr, key, lo, mid-1);
{{ '}' }}
Inversión de String — divide y vencerás
static String invertir(String s) {{ '{' }}
  if (s.length() <= 1) return s;
  return invertir(s.substring(1))
       + s.charAt(0);
{{ '}' }}
// invertir("abc") → "cba"

Recursión de cola — tail recursion

No es tail — hay trabajo pendiente tras la llamada
return n * factorial(n-1);
// "n *" se aplica DESPUÉS de regresar
Tail recursion — acumulador como parámetro
static long factTail(int n, long acc) {{ '{' }}
  if (n <= 1) return acc;
  return factTail(n-1, n*acc);
{{ '}' }}
// factTail(5, 1) → 120
// Java NO optimiza TCO; riesgo stack igual
Java NO aplica Tail Call Optimization. Incluso con tail recursion, cada llamada ocupa un frame. Para recursión profunda (n > ~5000) convierte a iteración manual o usa un trampolín (Supplier<T> encadenados).
