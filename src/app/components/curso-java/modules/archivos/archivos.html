38E/S

Lectura y Escritura de Archivos

Los streams de I/O se dividen en: byte streams (InputStream/OutputStream) y character streams (Reader/Writer). Siempre envuelve con Buffered* para rendimiento.

39E/S

NIO.2 & Paths (Java 7+)

java.nio.file.Path reemplaza a java.io.File. Files ofrece operaciones atómicas y atributos enriquecidos. WatchService permite vigilar directorios.

40E/S

Serialización de Objetos

Convertir un objeto a bytes (ObjectOutputStream) y restaurarlo (ObjectInputStream). La clase debe implementar Serializable. Los campos transient no se serializan.

Define siempre serialVersionUID para controlar la compatibilidad entre versiones de clase. Nunca serializes contraseñas.
