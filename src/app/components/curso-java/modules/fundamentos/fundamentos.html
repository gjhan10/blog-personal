01Módulo 1

Introducción a Java

Java es un lenguaje orientado a objetos, compilado a bytecode y ejecutado en la JVM. Multiplataforma por diseño: Write Once, Run Anywhere.

JDK
Java Development Kit — compilador javac, herramientas y JRE incluido.
JVM
Java Virtual Machine — interpreta el bytecode (.class) en la plataforma real.
JRE
Java Runtime Environment — necesario para ejecutar aplicaciones Java ya compiladas.
Ciclo de vida: Main.java → javac → Main.class (bytecode) → java (JVM) → Ejecución.

03Módulo 1

Variables y Tipos de Datos

Java es de tipado estático: el tipo se declara una vez y no cambia. Existen 8 tipos primitivos y tipos de referencia (objetos).

¿Qué es una variable en Java?

Una variable en Java es un nombre simbólico que se usa para almacenar un valor.

Estructura de declaración de una variable

<tipo_de_dato> <nombre_variable> = <valor>;
Ejemplo:
int edad = 25;
int a = 2, b, c = 10;

Reglas para nombrar variables

El nombre de la variable puede contener:

·
Letras (a-z, A-Z)
·
Dígitos (0-9)
·
El símbolo $ (dólar)
·
El símbolo _ (guión bajo)
!
Debe comenzar con una letra, $ o _
int edad1 = 30; // ✓ válido
int _total = 100; // ✓ válido
int $monto = 500; // ✓ válido
int 1numero = 10; // ✗ error de compilación
No puede ser una palabra reservada del lenguaje (int, String, goto,...).
Es sensible a mayúsculas y minúsculas (case-sensitive).

Tipos de variables según su ámbito y ciclo de vida

a) Variables locales
  • Declaradas dentro de un método, constructor o bloque.
  • No tienen valor por defecto — deben inicializarse antes de usarse.
  • Existen sólo mientras se ejecuta el bloque donde están.
void metodo() {{ '{' }}
  int x = 10;
  System.out.println(x);
{{ '}' }}
b) Variables de instancia
  • Declaradas dentro de una clase pero fuera de cualquier método.
  • Cada objeto tiene su copia independiente.
  • Se inicializan con valores por defecto si no se asignan manualmente.
class Persona {{ '{' }}
  String nombre;
  int edad;
{{ '}' }}
c) Variables estáticas (de clase)
  • Declaradas con la palabra clave static.
  • Una sola copia compartida por todas las instancias.
  • Existen desde que se carga la clase en memoria.
class Contador {{ '{' }}
  static int totalObjetos = 0;
{{ '}' }}

Conversiones de tipos

Todos los tipos primitivos son convertibles entre sí, a excepción de boolean.

Conversión implícita
Se produce automáticamente cuando no hay pérdida de datos. Java amplía el tipo de menor a mayor capacidad (widening).
int n = 45;
double x = n; // OK automático
Conversión explícita (casting)
Necesaria cuando hay posible pérdida de datos. Se indica el tipo destino entre paréntesis antes del valor (narrowing).
double a = 4.5;
int x = (int) a; // x = 4
Orden de ampliación: byte → short → int → long → float → double. Ir en sentido inverso requiere casting.

Tipos por referencia / tipos objeto

Almacenan la dirección de memoria donde vive el objeto, no el valor en sí.

¿Qué son tipos referencia?
  • Clases (String, Integer, Scanner, etc.)
  • Interfaces
  • Arrays (int[], String[], etc.)
  • Enumeraciones (enum)
  • Registros (Java 16+)
  • Cualquier objeto creado con new
Dos referencias, un objeto
Asignar una variable de referencia a otra no copia el objeto, ambas apuntan al mismo.
Object ob1 = new Object();
Object ob2 = ob1; // misma ref

¿Qué es la inferencia de tipos en Java?

La inferencia de tipos es la habilidad del compilador de Java para deducir automáticamente el tipo de una expresión sin que el programador tenga que declararlo explícitamente.

Métodos genéricos
Java puede deducir el tipo genérico a partir de los tipos de los argumentos del método.
static <T> T pick(T a, T b) {{ '{' }} return a; {{ '}' }}
String result = pick("Hola", "Mundo");
Operador diamante (<>)
Introducido en Java 7, permite omitir los parámetros genéricos en el constructor si el contexto lo deja claro.
List<String> lista = new ArrayList<>();

var para variables locales

Desde Java 10, puedes usar var para que el compilador identifique el tipo local automáticamente:

var mapa = new HashMap<String, Integer>();

Restricciones:

-
Es obligatorio asignar explícitamente un valor a la variable
var num = 10; // Válido
var customer; // error de compilación
var customer = null; // error de compilación
-
No es posible utilizarlo en declaraciones múltiples
var a,b=10; // incorrecto
var a= 10, b= 11; // incorrecto
-
Es válido usarlo en bucles for
for (var a=0; a<10; a++) {{ '{' }}
  System.out.println(a);
{{ '}' }}
var data = new int[]{{ '{' }}1,2,3{{ '}' }};
for (var value:data) {{ '{' }}
  System.out.println(value);
{{ '}' }}
-
En arrays no puede utilizarse con inicialización abreviada
var data = {{ '{' }}1,2,3{{ '}' }}; // Incorrecto

Expresiones lambda (Java 8)

También se infiere el tipo de los parámetros del lambda desde el contexto:

List<Integer> nums = List.of(1, 2, 3);
nums.forEach(n -> System.out.println(n));

Clasificación de operadores en Java

Java cuenta con 9 categorías de operadores, cada una con reglas específicas de aplicación y precedencia.

1. Operadores aritméticos

+, -, *, /, %

·
Reglas:
○
Se aplican a tipos numéricos (byte, short, int, long, float, double).
Operaciones con byte o short promocionan a int (regla de promoción aritmética):
byte a = 10, b = 20;
byte c = (byte) (a + b);
○
/ entre enteros realiza división entera truncada.
○
% (módulo) conserva el signo del dividendo:
System.out.println(5 % -2);
System.out.println(-5 % 2);

2. Operadores unarios

+, -, ++, --, !, ~

·
Reglas:
○
++ y -- pueden ser prefijo o sufijo:
■
++x: incrementa antes de usar.
■
x++: incrementa después de usar.
○
! solo se aplica a boolean.
○
~ solo a tipos enteros (invierte bits).

3. Operadores de asignación

=, +=, -=, *=, /=, %= etc.

·
Reglas:
○
Evaluación de derecha a izquierda:
int a, b, c;
a = b = c = 10;
○
Operaciones con += aplican conversión automática:
byte x = 10;
x += 5;
x = x + 5;

4. Operadores relacionales

<, >, <=, >=, ==, !=, instanceof

·
Reglas:
○
== y != para primitivos compara valores.
○
Para objetos compara referencias, no contenido (salvo que equals() se sobreescriba).
○
instanceof ahora (Java 16+) admite pattern matching:
if (obj instanceof String s) {{ '{' }}
  System.out.println(s.toUpperCase());
{{ '}' }}

5. Operadores lógicos

&&, ||, !

·
Reglas: Son short-circuit:
■
En a && b, si a es false, no evalúa b.
■
En a || b, si a es true, no evalúa b.

6. Operadores bit a bit

&, |, ^, ~, <<, >>, >>>

Reglas
  • Operan sobre enteros (byte, short, int, long).
  • >>: desplazamiento aritmético (mantiene signo).
  • >>>: desplazamiento lógico (rellena con ceros).
Ejemplo
int x = -8;
System.out.println(x >> 2);
System.out.println(x >>> 2);

7. Operadores condicionales

Ternario ? :

·
Reglas:
○
condicion ? valorSi : valorNo — ambos lados deben ser tipos compatibles:
int x = true ? 1 : 2;
int y = true ? 1 : "hola";

8. Operadores de comparación de objetos

·
== — compara referencias.
·
equals() — compara contenido (si está implementado).
Recordatorio: nunca confundir == con equals() para Strings:
String a = new String("hola");
String b = new String("hola");
System.out.println(a == b);
System.out.println(a.equals(b));

9. Operadores especiales

OperadorDescripción
newCrea objetos.
.Acceso a miembros.
[]Indexación de arrays.
::Referencias a métodos (Java 8+).
...Parámetros variables (varargs).
División entera: 10 / 3 = 3.
Para decimales: 10 / (double) 3 = 3.333...

06Módulo 1

switch — Expresión de Java 14+

Java 14 modernizó switch convirtiéndolo en expresión con la sintaxis de flecha ->, que elimina el break implícito y evita los fall-through accidentales.

Sintaxis clásica (Java 1–13)
int dia = 2;
String nombre;
switch (dia) {{ '{' }}
  case 1: nombre = "Lunes"; break;
  case 2: nombre = "Martes"; break;
  default: nombre = "?"; break;
{{ '}' }}
Expresión moderna (Java 14+)
int dia = 2;
String nombre = switch (dia) {{ '{' }}
  case 1 -> "Lunes";
  case 2 -> "Martes";
  default -> "?";
{{ '}' }};

09Módulo 1

break & continue

break termina el bucle inmediatamente. continue salta a la siguiente iteración. Ambos aceptan etiquetas para bucles anidados.

Usa break con etiqueta (outer: for...) para salir de bucles anidados sin banderas booleanas.
