33Genéricos

Genéricos (Generics)

Permiten escribir clases, interfaces y métodos que operan sobre tipos parametrizados. Proporcionan seguridad de tipos en tiempo de compilación y eliminan el cast manual.

Definición

  • Permiten que una clase puede operar con cualquier tipo de objeto Java (no pueden ser primitivos).
  • En la definición de la clase se emplea una letra para hacer referencia de forma genérica al tipo:
    class MyClass<T>{...}
  • Al crear un objeto de la misma, se debe especificar el tipo concreto con el que se va a trabajar:
    MyClass<String> mc = new MyClass<>();

Tipo genérico como parámetro

  • A la hora de definir un parámetro de tipo genérico, se debe emplear el operador comodín (?):
    public void mostrar(Caja<?> caja){
      System.out.println(caja.getValor());
    }
  • El método podrá ser llamado con un objeto Caja de cualquier tipo:
    Caja<String> c1 = new Caja<>("hola");
    Caja<Integer> c2 = new Caja<>(42);
    mostrar(c1);
    mostrar(c2);

Métodos genéricos

  • Una clase no genérica puede incluir métodos que utilicen un tipo genérico (en parámetros o como resultado).
  • Se incluirá la expresión <T> en la definición del método:
    public <T> void imprimir(T item){...}
    public <T extends Comparable<T>> void comparar(T item){...}
    public <T> T identidad(T item){...}
Definición
public class Utilidades {
  public <T> String tipoDe(T valor) {
    return valor.getClass().getSimpleName();
  }
}
Uso
Utilidades u = new Utilidades();
System.out.println(u.tipoDe("mundo")); // String
System.out.println(u.tipoDe(99));       // Integer
System.out.println(u.tipoDe(3.14));     // Double
SintaxisSignificado
<T>Tipo genérico sin restricción
<T extends Comparable<T>>T debe implementar Comparable
<? extends Numero>Wildcard — cualquier subtipo
<? super Integer>Wildcard — cualquier supertipo
34Lambdas

Expresiones Lambda (Java 8+)

Una lambda es una función anónima que implementa una interfaz funcional (con un único método abstracto). Sintaxis: (params) -> expresión.

Predicate<String> larga = s -> s.length() > 5;
Comparator<String> porLen = (a, b) -> a.length() - b.length();
Runnable tarea = () -> System.out.println("¡Lambda!");

Interfaces Funcionales

El paquete java.util.function provee las interfaces funcionales más comunes. Con andThen y compose puedes encadenar funciones.

InterfazMétodoDescripción
Function<T,R>apply(T)T → R
BiFunction<T,U,R>apply(T,U)T,U → R
Predicate<T>test(T)T → boolean
Consumer<T>accept(T)T → void
Supplier<T>get()() → T
36Streams

Stream API (Java 8+)

Un Stream es una secuencia de elementos que soporta operaciones funcionales encadenadas: intermedias (lazy, retornan Stream) y terminales (ejecutan la cadena).

TipoOperaciones
Intermediasfilter, map, flatMap, distinct, sorted, limit, skip, peek
TerminalesforEach, collect, count, sum, reduce, findFirst, anyMatch, allMatch
37Streams

Optional (Java 8+)

Optional<T> es un contenedor que puede o no tener valor. Elimina los if (x != null) y reduce NullPointerException. Nunca retornes null — retorna Optional.empty().

ifPresentOrElse (Java 9), stream() en Optional (Java 9), or(Supplier) (Java 9).

¿Qué es el mecanismo de type erasure en Java Generics?
A
Los genéricos se verifican en tiempo de ejecución con reflection
B
Los parámetros de tipo se eliminan en compilación; en bytecode List<String> es simplemente List
C
El compilador borra los genéricos solo en clases anónimas
D

✓ Type erasure: en tiempo de compilación se verifican los tipos genéricos, pero en el bytecode resultante se borran. List<String> se convierte en List. Por eso no puedes hacer new T(), instanceof List<String> ni crear arrays de tipo genérico.
✗ Type erasure: los genéricos existen solo en código fuente y compilación. En bytecode/runtime no hay información de tipo genérico. Consecuencia: no se puede hacer instanceof T ni instanciar new T().
