01Módulo 1

¿Qué es Spring Boot?

Spring Boot es un framework opinado sobre Spring Framework que elimina la configuración manual mediante auto-configuración, starters y un servidor embebido.

Spring Framework (sin Boot)
web.xml (servlet descriptor)
applicationContext.xml
dispatcher-servlet.xml
Configurar datasource manualmente
Deploy en Tomcat externo
Spring Boot
@SpringBootApplication
application.properties
Servidor Tomcat embebido
Auto-configuración inteligente
spring-boot-starter-web
Auto-Configuración
Detecta las dependencias en el classpath y configura beans automáticamente. Si añades spring-boot-starter-data-jpa, configura un DataSource, EntityManagerFactory y repositorios.
Starters
Dependencias curadas que agrupan todo lo necesario. spring-boot-starter-web incluye Spring MVC, Jackson, Tomcat embebido y validación.
Fat JAR
El plugin Maven/Gradle empaqueta toda la aplicación (código + dependencias + servidor) en un único JAR ejecutable: java -jar app.jar.
Opinado
Spring Boot toma decisiones por defecto razonables. Siempre puedes sobreescribir cualquier configuración cuando lo necesitas.
Spring Boot 3.x requiere Java 17+ y Spring Framework 6.x. Usa Jakarta EE 9+ (paquete jakarta.* en lugar de javax.*).
02Módulo 1

Spring Initializr

start.spring.io genera la estructura base de un proyecto Spring Boot en segundos. Elige dependencias, versión Java y sistema de build.

1
Abre start.spring.io y selecciona Maven o Gradle.
2
Elige Java 21 (LTS) y la última versión estable de Spring Boot 3.x.
3
Completa Group (com.empresa) y Artifact (mi-api).
4
Añade dependencias: Spring Web, Spring Data JPA, H2, Lombok.
5
Descarga el ZIP, descomprímelo y ábrelo en IntelliJ IDEA.
6
Ejecuta mvn spring-boot:run o usa el botón Run en el IDE.
<!-- pom.xml generado -->
<parent>
  <groupId>org.springframework.boot</groupId>
  <artifactId>spring-boot-starter-parent</artifactId>
  <version>3.3.0</version>
</parent>
El spring-boot-starter-parent gestiona versiones de todas las dependencias compatibles. Evita conflictos de versión.
03Módulo 1

Starters & Autoconfiguration

Los starters son POMs que agrupan dependencias relacionadas. La auto-configuración usa condiciones para activar beans solo cuando tiene sentido.

spring-boot-starter-web
Spring MVC + Tomcat embebido + Jackson (JSON) + Bean Validation. Activa DispatcherServlet auto-configurado.
spring-boot-starter-data-jpa
Hibernate + Spring Data JPA + JDBC. Configura DataSource, EntityManagerFactory y TransactionManager.
spring-boot-starter-security
Spring Security con configuración por defecto: HTTP Basic, forma de login, CSRF activo. Todo personalizable.
@Conditional*
@ConditionalOnClass, @ConditionalOnMissingBean, @ConditionalOnProperty. La auto-config solo actúa si se cumplen las condiciones.
@AutoConfiguration
@ConditionalOnClass(DataSource.class)
@ConditionalOnMissingBean(DataSource.class)
public class DataSourceAutoConfiguration {{ '{' }} ... {{ '}' }}
En Spring Boot 3, el archivo de auto-configuraciones cambió de spring.factories a META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports.

05Módulo 1

@SpringBootApplication

Esta anotación compuesta activa tres mecanismos fundamentales de Spring Boot en una sola línea.

@Configuration
Marca la clase como fuente de definiciones de beans @Bean. Equivale a un XML de configuración de Spring.
@EnableAutoConfiguration
Activa el mecanismo de auto-configuración. Spring Boot lee los registros en AutoConfiguration.imports y aplica solo los que cumplen las condiciones.
@ComponentScan
Escanea el paquete de la clase y sus subpaquetes buscando @Component, @Service, @Repository, @Controller.
@SpringBootApplication
public class MiApiApplication {{ '{' }}
  public static void main(String[] args) {{ '{' }}
    SpringApplication.run(MiApiApplication.class, args);
  {{ '}' }}
{{ '}' }}
Coloca la clase principal en el paquete raíz de tu aplicación para que @ComponentScan encuentre todos tus componentes.
06Módulo 1

Primera API REST

Con Spring Boot puedes tener una API REST funcional en menos de 10 líneas de código.

@RestController
@RequestMapping("/api/saludo")
public class SaludoController {{ '{' }}
  @GetMapping
  public String hola() {{ '{' }}
    return "¡Hola desde Spring Boot!";
  {{ '}' }}
  @GetMapping("/{{ '{' }}nombre{{ '}' }}")
  public Map<String, String> personalizado(@PathVariable String nombre) {{ '{' }}
    return Map.of("mensaje", "Hola, " + nombre);
  {{ '}' }}
{{ '}' }}
Ejecuta mvn spring-boot:run y accede a http://localhost:8080/api/saludo/Carlos. Jackson serializa el Map a JSON automáticamente.
Flujo de una petición
HTTP Request → DispatcherServlet → HandlerMapping → Controller → Service → Repository → Response
Jackson por defecto
Spring Boot auto-configura ObjectMapper. Cualquier objeto Java devuelto por un @RestController se convierte a JSON.
