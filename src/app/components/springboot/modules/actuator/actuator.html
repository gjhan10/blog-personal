Spring Boot Actuator

Monitoriza y gestiona tu aplicación en producción con endpoints HTTP listos para usar.

Dependencia
Agrega spring-boot-starter-actuator. Los endpoints se exponen bajo /actuator por defecto.
Exposición
management.endpoints.web.exposure.include=health,info,metrics,env,beans,mappings. Por defecto sólo health e info.
Health endpoint
Devuelve UP / DOWN / OUT_OF_SERVICE / UNKNOWN. Kubernetes usa /actuator/health/liveness y /actuator/health/readiness.
HealthIndicator custom
Implementa HealthIndicator → override health() → retorna Health.up().withDetail("key","val").build().
management:
  endpoints:
    web:
      exposure:
        include: "health,info,metrics,prometheus"
  endpoint:
    health:
      show-details: always
      probes:
        enabled: true
Nunca expongas /actuator/env o /actuator/shutdown sin autenticación — contienen propiedades sensibles.

Micrometer

Facade de métricas agnóstico del backend (Prometheus, Datadog, CloudWatch…).

Tipos de meter
Counter – sólo sube. Gauge – valor instantáneo. Timer – duración + count. DistributionSummary – histograma de valores.
Tags
Añaden dimensiones: Tags.of("status","200","method","GET"). Cada combinación es una serie temporal única.
@Timed
Anota un método con @Timed("mi.operacion") — requiere TimedAspect bean y AOP activo.
MeterBinder
Implementa MeterBinder → bindTo(MeterRegistry) para registrar métricas personalizadas al arranque.
@Component
class OrderMetrics implements MeterBinder {{ '{' }}
  public void bindTo(MeterRegistry r) {{ '{' }}
    Gauge.builder("orders.pending", queue, Queue::size)
      .tags("region", "eu").register(r);
  {{ '}' }}
{{ '}' }}

Prometheus & Grafana

Exporta métricas de Micrometer a Prometheus y visualízalas en dashboards Grafana.

Dependencia Prometheus
Añade micrometer-registry-prometheus. Expone /actuator/prometheus en formato text/plain 0.0.4.
Scrape config
En prometheus.yml: scrape_configs → job_name: springboot, metrics_path: /actuator/prometheus, targets: [host:port].
PromQL básico
rate(http_server_requests_seconds_count[1m]) — RPS. histogram_quantile(0.95, ...) — P95. jvm_memory_used_bytes — heap.
Dashboard Grafana
Importa dashboard ID 4701 (JVM Micrometer) desde grafana.com. Conecta datasource Prometheus primero.
# prometheus.yml
scrape_configs:
  - job_name: springboot-app
    metrics_path: /actuator/prometheus
    static_configs:
      - targets: ['localhost:8080']

Distributed Tracing

Rastrea peticiones a través de microservicios con Micrometer Tracing y Zipkin.

TraceId / SpanId
TraceId: identifica la traza completa (misma en todos los servicios). SpanId: identifica una unidad de trabajo dentro de la traza.
Propagación B3
Headers HTTP: X-B3-TraceId, X-B3-SpanId, X-B3-ParentSpanId, X-B3-Sampled. W3C TraceContext usa traceparent.
ObservationRegistry
API unificada en Spring Boot 3: Observation.start("op", registry).observe(() -> ...). Registra métricas + trazas + logs automáticamente.
MDC Correlation
Micrometer Tracing inyecta traceId y spanId en MDC. Logback los incluye automáticamente en los logs.
# application.yml
management:
  tracing:
    sampling:
      probability: 1.0 # 100% en dev
spring:
  zipkin:
    base-url: http://localhost:9411
Añade micrometer-tracing-bridge-brave + zipkin-reporter-brave para enviar spans a Zipkin.
